# commits

`commits` — скилл, который задаёт ИИ-агенту правила работы с коммитами. Агент уже умеет
обращаться с Git и составлять сообщения коммитов. Скилл создали, чтобы агент каждый раз
проверял, какие правки образуют одно логически завершённое изменение, и объяснял в сообщении,
зачем оно понадобилось. Например, Git позволяет записать исправление ошибки и попутный
рефакторинг в один коммит. Тогда сложнее откатить только одно изменение.

## Что агент проверяет перед коммитом

Перед каждым коммитом агент перечитывает изменения, которые собирается записать в Git. Так он
может заметить, что в коде осталась временная строка для отладки или в файл случайно попал пароль.
[Что проверить в составе коммита](references/contents.md)

Агент также сверяет формат сообщения с правилами проекта. Если проект своего формата не задал,
действуют правила скилла.
[Правила и примеры сообщений](references/message.md)

## Когда ещё нужен скилл

Git может запускать автоматические проверки при попытке создать коммит. Если проверка
отклоняет его, агент исправляет то, на что она указала. Например, при слишком длинной первой
строке агент сокращает сообщение и снова запускает `git commit`.

Скилл также помогает разобрать правки для разных задач, если они оказались в одном файле,
или поправить, разделить либо объединить коммиты, которые ещё никуда не отправлены.
[Как разделить изменения](references/split.md) ·
[Работа с перемешанными правками и неотправленными коммитами](references/repair.md)
