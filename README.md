# commits

Скилл коммитов для ИИ-агента Claude Code. Прочитав этот файл, вы узнаете, чему скилл учит агента,
когда агент его поднимает и как скилл попадает на машину.

## Чему учит

Скилл — инструкция для агента в файле `SKILL.md`. Этот учит агента:

- делить изменения на коммиты: один коммит — одно логически завершённое изменение;
- писать сообщение: первая строка — что изменилось по сути, тело — почему;
- не класть в коммит лишнего: следы работы, отладку, секреты, которые не ловят проверки;
- поправить, разрезать или склеить коммит, который ещё никуда не отправлен.

## Когда агент его поднимает

Агент постоянно видит краткое описание скилла и поднимает его, когда задача подходит под описание:
перед каждым коммитом, когда хук отклонил коммит и когда нужно поправить ещё не отправленный коммит.
В проекте по Стандарту процесса разработки Центра к скиллу ещё направляет скилл-оркестратор
`standard`.

## Как скилл попадает на машину

В Стандарте скилл ставит скрипт `install` репозитория `standard`: этот репозиторий лежит в папке
Стандарта рядом со `standard`, а `install` ставит на него ссылку `~/.claude/skills/commits`, где
Claude Code ищет скиллы пользователя. Как получить папку Стандарта — README репозитория `standard`.

Вне Стандарта склонируйте репозиторий и поставьте ссылку сами:

```bash
git clone <адрес Gitea>/<организация>/commits.git ~/projects/commits
mkdir -p ~/.claude/skills
ln -s ~/projects/commits ~/.claude/skills/commits
```

Проверка — `ls -l ~/.claude/skills/commits` показывает ссылку на папку репозитория. Агент увидит
скилл в новой сессии `claude`. Как править скилл — [CONTRIBUTING.md](CONTRIBUTING.md).
